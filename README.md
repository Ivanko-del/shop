# Maison — ательє сучасного одягу

Демонстраційний інтернет-магазин одягу. Статичний фронтенд без фреймворків,
збірки та бекенду: три HTML-сторінки, один стилевий файл і два скрипти.

**Живий сайт:** див. Deployments у Vercel
**Стек:** HTML + CSS + vanilla JS (ES2020), Fraunces / Inter / IBM Plex Mono, Font Awesome

---

## Структура

| Файл | За що відповідає |
|---|---|
| `index.html` | Головна: hero, категорії, бестселери з фільтром, редакційний блок, статистика, відгуки, промо |
| `product.html` | Картка товару. Модель обирається з `?id=` — наприклад `product.html?id=coat` |
| `cart.html` | Кошик, підсумок замовлення, промокод, рекомендації |
| `styles.css` | Уся верстка. Поділено на 10 нумерованих розділів — від токенів до 3D і адаптиву |
| `script.js` | Каталог, стан кошика, анімації, оверлеї, доступність |
| `theme-init.js` | Виставляє тему до першого відмалювання. Окремим файлом, щоб не було inline-скрипта |

## Як запустити

Потрібен HTTP-сервер — сторінки працюють і з `file://`, але краще перевіряти так,
як воно піде в продакшн:

```bash
python3 -m http.server 8000
# → http://127.0.0.1:8000
```

## Дизайн-система

Усі кольори, типографіка, відступи, тіні й easing описані токенами в `:root`
(`styles.css` розд. 1). Темна тема — це перевизначення тих самих токенів під
`:root[data-theme="dark"]`, тому окремих «темних» правил майже немає.

Окремо винесені токени `--inverse-*` для блоків, які мусять залишатися темними
в обох темах (біжучий рядок, промо-баннер, тост). Без них вони інвертувалися б
разом із `--ink` / `--paper` і втрачали контраст.

Типографіка плавна через `clamp()`, сітки — від 320px, з брейкпоінтами на
420 / 620 / 760 / 900 / 1100.

## Анімації

- **Scroll reveal** — `IntersectionObserver` з каскадними затримками для
  контейнерів із `data-stagger`. Стилі вмикаються лише класом `.js`, тому без
  JS контент видно одразу.
- **3D** — модуль `[data-tilt]`: поворот за курсором і блиск, що біжить по
  поверхні. Пропускається для тач-вводу, бо в тапа немає `pointerleave`, яким
  скинути кут.
- Куб із шести граней у hero, шари глибини в промо-баннері й відгуках, hinge-відкриття
  модалок, біжучий рядок, лічильники, індикатор прокрутки, таймер акції,
  завіса при переходах між сторінками.

Два неочевидних обмеження, на які варто зважати при правках:

1. `overflow: hidden` (він є на `.swatch`) **сплющує** свої 3D-дочірні елементи.
   Тому шари глибини — це сусіди плитки зображення, а не її діти.
2. `translateZ` під `perspective` **збільшує** елемент і відштовхує його від
   центру перспективи. Через це нижче 900px hero-картки зміщені всередину сцени —
   інакше вони вилітають за вьюпорт.

Усе під `prefers-reduced-motion`: tilt, куб і reveal вимикаються, числа
лічильників лишаються фінальними.

## Кошик

Стан живе в `localStorage` під ключем `maison-cart` і є єдиним джерелом правди:
бейдж у хедері рахується з нього на всіх сторінках, а друга вкладка
синхронізується через `storage`-подію. Видалення позиції пропонує «Відмінити».

Ніщо зі сховища не вважається довіреним: `sanitizeLine()` звіряє кожну позицію
з каталогом — невідомі `id` відкидаються, розмір і колір приводяться до
реальних варіантів, кількість клампиться до 1..10. Побитий JSON деградує, а не
кидає виняток.

## Безпека

- `escapeHTML()` обгортає **кожне** значення, що потрапляє в `innerHTML`.
  Контракт функції — текстові вузли та **лапковані** атрибути; для
  нелапкованих вона недостатня (не екранує пробіл, `/`, `=`).
- Пошук товару йде через `hasOwnProperty`-guard, тому `?id=__proto__` і
  `?id=constructor` не повертають члени `Object.prototype`.
- CSP через `<meta http-equiv>`: `script-src 'self'` без `unsafe-inline`,
  `object-src` / `base-uri` / `form-action` / `connect-src` — `'none'`.
  Саме тому в розмітці немає жодного inline-скрипта й жодного атрибута
  `style=`, а кольорові точки будуються через CSSOM.

Відкриті пункти:

- **SRI** на два CDN-стилі не виставлено. Порахувати хеш:
  `curl -s <url> | openssl dgst -sha384 -binary | openssl base64 -A`
- **`frame-ancestors`** у `<meta>` ігнорується за специфікацією — потрібен
  справжній HTTP-заголовок від хостингу.

## Доступність

Skip-link, focus trap і повернення фокуса в оверлеях, навігація стрілками в
пошуку (`Cmd`/`Ctrl` + `K` відкриває), `aria-expanded` / `aria-pressed` на
перемикачах, live-регіони на підсумку й статусах, задизейблені кнопки степера
на межах діапазону.
